# Validation Process

This document describes the process used to validate certificate authenticity through the QR code embedded in each certificate.

## Objective

The validation mechanism makes it possible to verify that the information presented on a certificate matches the validation document originally generated by the system.

This helps identify modified certificates, altered information, or certificate numbers used incorrectly.

## Validation Process

```text
Certificate
     ↓
QR code scan
     ↓
Validation URL
     ↓
Validation document in Google Drive
     ↓
Information comparison
```

## 1. QR Code Scan

Each certificate contains a QR code generated during the automation process.

The user can scan it using a mobile device or any compatible QR code reader.

## 2. Access to the Validation Document

The QR code contains the URL of the validation document stored in Google Drive.

When scanned, the user is redirected directly to that document.

## 3. Information Available for Validation

The validation document contains the main information associated with the certificate:

* Name
* Course
* Company
