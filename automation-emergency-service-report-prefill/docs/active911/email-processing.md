# Email Processing

This document describes how the email generated by **Active911** is processed within the automation workflow.

## Email Source

Each time an alarm is generated in **Active911**, the platform automatically sends an email containing the available incident information.

This email serves as the data source that initiates the service report prefill process.

## Detection in Make

The **Make** scenario periodically checks the email inbox.

The check runs approximately every **45 minutes** and searches for unread messages sent from the email address used by Active911.

When a new email is found:

1. It is identified as pending processing.
2. It is marked as read.
3. Its content is sent to the artificial intelligence module.

## AI Processing

The AI model analyzes the email content and extracts the relevant service information.

The result is structured in JSON format:

```json
{
  "correo": "",
  "estacion": "",
  "active911": "",
  "Cecom": "",
  "calle": "",
  "Colonia": "",
  "Incidente": "",
  "giro": "",
  "Unidades": ""
}
```

## Extracted Fields

| Field      | Description                              |
| ---------- | ---------------------------------------- |
| `correo`   | Email address associated with the report |
| `estacion` | Station assigned to the service          |
| `acti`     |                                          |
